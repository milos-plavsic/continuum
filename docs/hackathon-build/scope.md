# Scope: winning succession vertical slice

Build one procurement incident proving that a valid institutional obligation can
survive a compromised agent. Continuum detects missing expected evidence,
correlates it with an injection marker and denied tool attempt, makes a
deterministic policy decision, fences the predecessor, transfers a minimum
authorized manifest, and lets a registered successor create one sandbox vendor
record through an idempotent gateway.

## In scope

- Succession state machine, epoch fencing, manifest, and roll-forward recovery.
- Versioned agent registry with capabilities, memory scopes, and deployment identity.
- Deterministic canonical fixture, negative controls, and measurable evaluation.
- Persistent governed sandbox side effect and duplicate-delivery proof.
- Action and memory denial for the retired predecessor.
- Incident evidence view, architecture diagram, demo script, and cloud proof plan.

## Out of scope

- General fleet administration, arbitrary workflows, live IAM mutation, a full policy
  language, production vector search, and autonomous prompt rewriting.
- Universal exactly-once claims. The bounded guarantee covers effects admitted by
  Continuum with a stable idempotency key and a reconcilable adapter.
