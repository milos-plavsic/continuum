# Product requirements

## User and outcome

An enterprise agent-platform operator must be able to see why an obligation is
at risk, approve or audit the response, and prove that authority and minimum
context moved to a successor without duplicating the external effect.

## Acceptance outcomes

1. Silence alone requests investigation and never proves compromise.
2. Quarantine requires cited injection, anomalous-action, and missed-evidence events.
3. The predecessor is fenced before the successor becomes active.
4. The transfer manifest includes the obligation and approved memory while excluding
   raw untrusted input and revoked memory.
5. A persistent sandbox vendor record is created once despite redelivery.
6. The predecessor receives stable action and memory denial reasons.
7. A replayable timeline links evidence, proposal, policy, succession, execution,
   and verification.
8. A registry exposes lineage, immutable artifact identity, capabilities, scopes,
   lifecycle status, and epoch.
9. Automated evaluation reports observed results without presenting unrun cloud or
   live-model claims as facts.
