## Title

Continuum — The Agent Failed. The Promise Did Not. | All Things Agentic Demo

## Description

Continuum is a governed succession control plane that keeps an institution's
promise alive when the autonomous agent responsible for it fails.

This video is the official demonstration prepared for Continuum's entry in the
2026 All Things Agentic Hackathon. It is also a standalone presentation for
anyone curious about reliable agentic systems, safe handoffs, bounded AI
authority, idempotent action, and independently verifiable outcomes.

In one 3:54 proof-first run, Continuum detects missing evidence, constrains
Gemini 3.6 to eligible successors, fences the failed predecessor, transfers
only authorized context, completes one reversible supplier-assurance effect,
and lets a separate read-only verifier—not the executing agent—declare the
result.

Built with Google ADK and Gemini 3.6 Flash on Vertex AI, plus Cloud Run,
Firestore, Cloud Tasks, Pub/Sub, Cloud Trace/OpenTelemetry, Model Armor, and
Cloud Storage. A verifier-gated learning branch also uses Gemma 4, Veo 3.1 Lite,
and Lyria 3.
